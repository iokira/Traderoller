## English

### What is this?

Traderoller adds a **Reroll** button to untraded villager trade screens.
Press it to instantly randomize the villager's trades — no more breaking and replacing job site blocks.

### Features

- **Reroll button** appears on the trade screen of any employed, untraded villager
- Randomizes all trades instantly, just like reassigning a job site block would
- Items placed in the trade input slots are safely returned to your inventory before rerolling
- Works in both **singleplayer and multiplayer** (required on both client and server)
- The button is hidden once you have traded with the villager even once

### Requirements

| Component | Version |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x |

> **Note:** This mod must be installed on **both the client and the server** in multiplayer.

### Installation

1. Install [NeoForge 21.1.x](https://neoforged.net/) for Minecraft 1.21.1
2. Download the latest `traderoller-*.jar` from [CurseForge](https://www.curseforge.com/)
3. Place the `.jar` file into your `mods/` folder
4. Launch the game

### How to Use

1. Find a villager with a job (not a Nitwit or unemployed)
2. Open the trade screen — a small **R** button appears in the top area
3. Press **R** to reroll the villager's trades
4. Repeat until you get the trades you want (only works while the villager is untraded)

## 日本語

### どんな Mod?

Traderoller は、未取引の村人の取引画面に **Reroll ボタン** を追加する Mod です。
ボタンを押すだけで取引内容をランダムに変更できます。職業ブロックを破壊して再設置する手間が不要になります。

### 特徴

- 有職かつ未取引の村人の取引画面に **Reroll ボタン**（R）が表示されます
- ボタンを押すと取引内容がランダムに変更されます
- リロール時に取引入力スロットのアイテムをインベントリへ自動返却します
- **シングルプレイ・マルチプレイ**両対応（マルチプレイ時はサーバーにも導入が必要です）
- 一度でも取引した村人にはボタンが表示されません

### 必要環境

| 項目 | バージョン |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x |

> **注意：** マルチプレイ時は**クライアントとサーバーの両方**に導入してください。

### 導入方法

1. Minecraft 1.21.1 用の [NeoForge 21.1.x](https://neoforged.net/) をインストール
2. [CurseForge](https://www.curseforge.com/) から最新の `traderoller-*.jar` をダウンロード
3. `.jar` ファイルを `mods/` フォルダに配置
4. ゲームを起動

### 使い方

1. 職業を持つ村人（ニート・無職以外）を用意します
2. 取引画面を開くと、上部に小さな **R** ボタンが表示されます
3. **R** を押して取引内容をリロール
4. 気に入った取引が出るまで繰り返しましょう（未取引の間のみ有効）
